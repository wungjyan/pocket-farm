# 掌上农场 MVP 项目总览

## 1. 项目目标

掌上农场是一个轻量级农场生产管理小程序。

目标不是建设完整农业 ERP，而是围绕：

“农场 → 地块 → 一次种养生命周期”

实现一个简单、清晰、能够实际使用的生产管理闭环。

核心流程：

创建农场
→ 添加成员
→ 创建地块
→ 开始种养
→ 记录农事
→ 采收 / 捕捞 / 出栏
→ 结束种养

---

## 2. 产品组织结构

用户可以加入多个农场。

一个农场可以拥有多个成员。

关系：

User
↓
FarmMember
↓
Farm

用户在不同农场中的角色可以不同。

例如：

张三
- 开心农场：OWNER
- 生态农场：ADMIN
- 鱼塘基地：MEMBER

MVP 使用手机号验证码识别用户。开发／测试环境允许使用受配置保护的测试验证码；正式环境改接短信验证码服务。微信登录不属于 MVP 范围。

---

## 3. 地块是产品信息聚合中心

用户日常生产管理主要围绕地块展开。

一个地块详情应能够看到：

- 地块基本信息
- 当前种养
- 历史种养
- 农事记录
- 收获记录

用户可以从地块直接：

- 开始种养
- 记农事
- 采收 / 捕捞 / 出栏
- 结束种养

---

## 4. Production 是种养生命周期核心

系统内部统一使用 `Production` 表示：

“某个地块上的一次具体种养生命周期”。

例如：

1号大棚
+
黄瓜
+
2026-08-14 开始

就是一条 Production。

用户界面不要出现：

- 生产批次
- 种植计划
- 生产计划

等内部系统概念。

前端使用自然业务术语：

- 开始种植
- 开始养殖
- 当前种养
- 历史种养
- 采收
- 捕捞
- 出栏
- 结束种植
- 结束养殖

---

## 5. 单地块原则

MVP 明确规定：

一个 Production 只关联一个 Plot。

不做：

- 一次种植多个地块
- 批量种植
- 批量采收
- 批量结束
- ProductionPlan

例如三个大棚同时种黄瓜：

不是一条 Production 关联三个地块。

而是：

Production A → 1号大棚
Production B → 2号大棚
Production C → 3号大棚

未来如果需要批量功能，可以批量创建这些独立记录，不改变核心模型。

---

## 6. 一个地块允许多次种养

例如：

1号大棚

2026-03-01
黄瓜
已结束

2026-08-14
黄瓜
进行中

这两次必须是两条完全独立的 Production。

不能根据：

plotId + speciesId

推断具体种养。

所有生产相关业务必须通过 `productionId` 明确关联。

---

## 7. 一个地块允许多个当前种养

不要限制一个地块只能有一条 ACTIVE Production。

例如一个地块可以同时存在：

黄瓜
+
生菜

两条当前 Production。

因此相关业务必须能够处理一个 Plot 存在多个 ACTIVE Production 的情况。

---

## 8. 农事与 Production 的关系

农事首先属于地块。

因此：

plotId：必填
productionId：可空

没有种养的地块也可以记录：

- 翻耕
- 清沟
- 灌溉
- 消毒
- 清塘

等农事。

---

## 9. 收获与 Production 的关系

采收、捕捞、出栏必须属于某一次具体 Production。

因此：

HarvestRecord.productionId：必填

一次 Production 可以：

- 0 次收获
- 1 次收获
- 多次收获

收获不会自动结束 Production。

---

## 10. 结束种养

结束种养不是单独的业务实体。

它是 Production 状态变化：

ACTIVE
→
ENDED

记录：

endedOn

即可。

没有任何 HarvestRecord 的 Production 同样允许结束。

---

## 11. MVP 包含

核心模块：

- User / Auth
- Farm
- FarmMember
- Plot
- Species
- Production
- FarmOperation
- HarvestRecord

---

## 12. MVP 不包含

暂时不实现：

- 企业体系
- 组织架构
- 部门
- 岗位
- 自定义角色
- 复杂 RBAC

- ProductionPlan
- 种植计划
- 批量种养
- 批量采收
- 批量结束

- 农资档案
- 农资库存
- 入库 / 出库

- 销售
- 客户
- 订单
- 仓储

- 审批
- 产品溯源
- 复杂统计报表
- 统计大屏

- AI 助手

- 微服务
- Redis
- MQ
- Celery
- Elasticsearch

---

## 13. MVP 完成标准

用户能够完整完成：

登录
→
创建农场
→
添加成员
→
创建地块
→
开始一次种养
→
记录多次农事
→
记录多次采收 / 捕捞 / 出栏
→
结束种养
→
在地块详情查看完整历史

同时支持：

空闲地块
→
直接记录农事

以及：

同一个地块
→
不断产生新的 Production 生命周期

达到以上目标后停止继续扩充功能，进入实际使用验证。
