# 掌上农场新 UI 设计系统

## 1. 范围与状态

本规范以首页、AI、农场、我的四个 Tab 的已验证真机界面为基线，适用于后续二级页面的逐页改造。

它不修改或继承 `docs/refactor/` 中的旧设计记录。设计 token 的代码源为 `apps/miniapp/src/styles/design-tokens.scss`；本文用于说明使用规则，不替代代码中的具体值。

当前目标是让小程序在户外强光和日常操作中保持清晰、轻量、可触达：用深森林绿标识关键动作或核心数据，用薄荷绿表达低权重强调，用雾白和细边框组织信息。

## 2. 颜色

| 语义 | Token | 值 | 用途 |
| --- | --- | --- | --- |
| 页面底 | `$pf-color-page` | `#F6F8F6` | 所有页面的基础画布 |
| 表面 | `$pf-color-surface` | `#FFFFFF` | 卡片、输入框、分组列表 |
| 弱表面 | `$pf-color-surface-muted` | `#F1F4F2` | 中性标签、禁用或低权重区域 |
| 薄荷表面 | `$pf-color-primary-soft` | `#EDF8F1` | 图标承托、状态标签、序号 |
| 主色 | `$pf-color-primary` | `#006C49` | 主操作、选中态、核心数字 |
| 深主色 | `$pf-color-primary-strong` | `#006445` | 数据卡的收束端、强调文字 |
| 按压色 | `$pf-color-primary-pressed` | `#00583C` | 主操作按压态 |
| 主文字 | `$pf-color-text` | `#17261F` | 标题、核心业务内容 |
| 次文字 | `$pf-color-text-secondary` | `#53645A` | 次级正文、非核心信息 |
| 辅助文字 | `$pf-color-text-muted` | `#748178` | 时间、说明、占位信息 |
| 分割线 | `$pf-color-divider` | `#E0E9E3` | 分组内分隔和常规边框 |
| 外轮廓 | `$pf-color-outline` | `#D3E1D8` | 需要比常规分割线更明确的描边 |

危险、警告和信息色只用于反馈状态，不能替代主色承担普通操作。不要引入深色模式、蓝紫主色、暖米色底或玻璃拟态。

## 3. 空间与触控

空间以 `8rpx` 为基础单位：`8 / 16 / 24 / 32 / 40 / 48 / 64rpx`。

- 页面左右内边距使用 `32rpx`。
- 同一层级的卡片和入口间距使用 `16rpx`。
- 内容区块之间使用 `40–48rpx`；不要用无意义的空白填充页面。
- 卡片内部默认使用 `20–24rpx` 内边距，列表行使用 `22–24rpx` 水平内边距。
- 普通可点击行高度至少 `96rpx`；列表入口推荐 `104rpx`；主操作和快捷入口按内容提高高度。
- 底部固定区域必须为安全区和 Tabbar 留出额外空间。

## 4. 字体与信息层级

使用系统字体，不依赖未随小程序打包的自定义字体。

| 层级 | 推荐 token / 尺寸 | 用途 |
| --- | --- | --- |
| 欢迎语 | `$pf-font-size-display` / `46rpx` | 首页唯一的展示级标题 |
| 区块标题 | `$pf-font-size-section` / `30rpx` | 农场概览、最近动态、服务分组 |
| 列表标题 | `$pf-font-size-title` / `26rpx` | 操作入口、种养名称、菜单标题 |
| 正文 | `$pf-font-size-body` / `24rpx` | 普通内容 |
| 标签与说明 | `$pf-font-size-label` 或 `$pf-font-size-caption` | 时间、数量单位、辅助信息 |

标题使用 `720` 左右的字重，列表标题使用 `650`，辅助信息保持 `500`。说明文字只在能帮助理解当前操作或数据时出现，不能为填充卡片而添加。

## 5. 圆角、边框与阴影

| 元素 | Token | 规则 |
| --- | --- | --- |
| 表单控件、图标底 | `$pf-radius-control` / `16rpx` | 紧凑且易点按 |
| 紧凑选择卡 | `$pf-radius-card-compact` / `20rpx` | 建议问题、并列统计内卡 |
| 标准卡片与分组列表 | `$pf-radius-card` / `24rpx` | 页面中最常用的卡片尺度 |
| 主操作和大面板 | `$pf-radius-card-lg` / `28rpx` | 首页主操作、外层概览面板 |
| 标签 | `$pf-radius-pill` | 只用于日期、角色、状态等短信息 |

标准表面以 `1rpx` 的 `$pf-color-border` 区分。默认不加阴影；只有需要从页面画布中抬起的轻量卡片使用 `$pf-shadow-card`。主操作使用 `$pf-shadow-action`，浮层使用 `$pf-shadow-raised`。不得叠加边框、阴影和多层嵌套卡片来制造层级。

## 6. 卡片与列表

### 主操作卡

主操作是当前页面唯一的高强调动作。使用 `$pf-gradient-action`、反白文字和弱装饰图形；同一屏不应出现第二张同级绿色动作卡。

### 数据概览卡

核心统计可使用 `$pf-gradient-data`，但必须由数字、单位和信息分隔线明确它是数据而不是提交按钮。次要统计使用弱表面和细边框。

### 分组列表

连续的同类入口合并在一张 `$pf-radius-card` 分组表面内，以细分割线区分行。不要为每一行单独套一张卡。

### 快捷入口

首页的三项快捷入口可并列排布。图标使用薄荷承托，标题优先，说明限一行且必须提供实际决策或操作价值。

## 7. 图标与状态

- 导航、统计、状态和 AI 标识使用 Lucide 的细线图标；描边颜色随当前语义色变化。
- 种养、农事、收获、地块等业务动作可使用现有业务图标，保持同一尺寸和薄荷承托规则。
- 一个区域只使用一种图标表达方式；图标不能替代必需的业务文字。
- 状态标签使用薄荷绿或中性弱表面。没有真实数据来源时，不展示“在线”等状态。
- 数据缺省统一使用 `PfEmptyState`，由页面传入明确的业务标题和 Lucide 图标；禁止使用没有上下文的“暂无数据”。
- 缺省组件提供页面、卡片和行内三种结构。页面级默认不添加卡片边框与阴影，局部区块根据现有信息层级选择卡片或行内结构。
- 缺省操作只在能够直接解除当前状态时出现：主要下一步使用紧凑主按钮，清除筛选等低权重操作使用文字按钮；页面已有同一操作入口时不得重复显示。
- 加载、失败、功能关闭和前置条件缺失不属于数据缺省，不与 `PfEmptyState` 混用。

## 8. 二级页面改造规则

后续改造按页面逐一进行，不因引入新 token 而一次性重排所有二级页面。

已完成页面和当前约定见“页面改造台账”，每次完成新的页面改造后同步更新该台账。

1. 先将页面的颜色、圆角、阴影和间距迁移到 `design-tokens.scss` 的语义 token。
2. 再根据该页的核心任务确定一个主操作，合并重复卡片或重复边框。
3. 保持已有业务字段、跳转、权限提示和错误状态，不以视觉重构名义扩展功能。
4. 每页完成后检查：安全区、长文本截断、列表点击高度、空态和加载态。
5. 新增页面直接使用 token；禁止在页面内重新声明与全局同义的颜色、阴影或圆角变量。

## 9. 禁止项

- 不使用蓝紫夜间主题、暖米色配暖橙、复古 serif 标题或仿 Claude 的视觉语言。
- 不使用大圆角的无目的容器、无目的嵌套卡片或显著厚重阴影。
- 不使用玻璃模糊、透明叠层等会降低户外可读性的效果。
- 不用描述性文案填补空白；保留对任务有意义的留白。

### 10.3 详情页当前约定

- 二级详情页使用微信原生导航栏，页面内容不重复绘制标题或返回按钮。
- 同类“编辑详情”操作统一放在顶部摘要卡右侧，使用薄荷底和主色文字；只读状态不显示编辑入口。
- 页面跳转入口使用主文字色和统一右箭头。不能因为入口位于列表首项就改成绿色；绿色只表达明确的主操作、状态、选中态或核心数据。
- 连续字段合并为一张分组列表，常规行高使用 `104rpx`，备注等长文本改为上下布局。
- 删除使用独立的浅红危险按钮，并保留二次确认。如果页面只剩删除操作，不显示没有信息价值的“操作”区块标题。
- 关联种养已经结束时，农事详情和收获详情维持只读，不显示编辑和删除；种养详情仍允许查看既有收获记录。
- 加载态、失败态、删除确认色、卡片边框、圆角和间距统一使用新设计系统的语义 token。

### 10.4 种养流程当前约定

- “开始种养”流程当前覆盖 `pages/productions/start`、`pages/species/index`、`pages/productions/form`、`pages/plots/index` 和 `pages/farm-plots/index`。
- 列表页工具栏使用胶囊控件：筛选器为白底加外轮廓描边的胶囊，筛选生效时切换薄荷底和主色文字，不加前导图标；页面主动作使用薄荷胶囊，可带加号前导图标；右侧计数保持弱化说明。
- 地块列表项保持独立卡片，不合并为分组列表；行内种养标签使用胶囊标签，选中行的标签底色转为白色以维持对比。
- 表单控件的默认高度为 `96rpx`，字段间距为 `32rpx`；字段标签、必填标记、占位文字和图标颜色必须使用语义 token。
- 选填字段使用可展开的分组标题承接：标题以绿色短标记、区块级字号和箭头表达层级，不使用与输入控件相同的白色描边卡片。
- 连续的同类选择项使用一张分组列表和行间分割线，不为每个选项单独添加卡片或阴影。
- `ProductionForm` 和 `FixedUnitNumberField` 是共享组件。种养编辑页会同步继承组件样式，但在单独完成页面结构和状态检查前，不计入已完成页面。

### 10.5 台账维护规则

1. 页面完成结构、样式和交互检查后，即可将状态写为“已完成”。
2. 仅替换颜色或引入 token，但尚未检查信息层级和交互语义时，状态仍记为“未改造”。
3. 后续页面若形成新的通用规则，先更新本规范，再在台账中记录受影响页面，避免页面之间逐渐产生不同实现。
