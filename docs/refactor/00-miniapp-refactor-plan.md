## 3. 已确认的界面基线

### 3.1 卡片

- 首页和农场 Tab 使用白色表面与设计 token 中的浅阴影区分层级。
- 不使用大面积绿色卡片背景。
- 连续记录列表可以使用细分隔线；地块等可独立进入的业务对象使用彼此分开的白底浅阴影卡片，不在同一张卡片中用分割线串联。
- 不增加解释性副文案，不使用无目的嵌套卡片。

### 3.2 行尾箭头

- 首页与农场 Tab 已复用 `apps/miniapp/src/components/PfRowChevron.vue`；其他页面后续逐页替换。
- 图标资源固定为 `/static/icons/home/chevron-right.png`。
- 视觉尺寸固定为 `30rpx × 30rpx`。
- 选择态勾选、下拉箭头和页面返回箭头不属于行尾导航箭头。
- 本轮不修改首页与农场 Tab 之外页面的既有箭头。

### 3.3 农场概览

- “全部地块”包含闲置地块，展示地块数与总面积。
- “闲置地块”指没有 ACTIVE Production 的地块，展示闲置地块数与闲置总面积。
- 地块面积改为必填前，缺失面积按 `0` 汇总。
- 两组数据使用等权重的白底浅阴影卡片，点击均进入当前农场地块列表。

### 3.4 当前种养

- 标题右侧按 `speciesId` 去重显示“共 x 种”。
- 同一种类存在多条 ACTIVE Production 时，列表仍逐条展示。
- 行内不显示行业图标和重复的“进行中”状态。

## 4. R5：农场概览地块筛选列表

### 4.1 目标

为农场 Tab 的“全部地块”和“闲置地块”概览卡提供独立的摘要列表页面；不修改首页“地块管理”和既有地块管理／选择页面。

### 4.2 交互与数据口径

- 默认筛选为“全部种类”，展示当前农场全部地块。
- 筛选器使用小程序原生 `picker mode="selector"`，选项为“全部种类”、当前 ACTIVE 种养种类（按 `speciesId` 去重）和“空闲地块”。
- “空闲地块”指没有 ACTIVE Production 的地块。
- 一个地块存在多个 ACTIVE Production 时，可以同时命中多个种类筛选。
- 从“全部地块”卡进入时携带全部筛选，从“闲置地块”卡进入时携带空闲筛选。
- 列表行展示地块名称、类型、面积、当前种养标签，点击后进入既有地块详情页。
- 每个地块作为独立的白底浅阴影卡片展示，卡片之间使用间距区分，不使用一个外层列表卡片包裹多个地块。
- 截图中的地图、搜索、地块分组、悬浮新增按钮和作物图片不属于本次范围。

### 4.3 实现范围

- 新增 `pages/farm-plots/index` 页面和路由。
- 复用既有地块和 ACTIVE Production 接口，前端组装当前农场的地块摘要与筛选选项。
- 保留 `/pages/plots/index` 的管理／选择模式及其所有既有调用方。

### 4.4 验收

- 全部地块、闲置地块两个入口分别带入正确初始筛选。
- 无 ACTIVE Production 的地块只出现在“全部种类”和“空闲地块”结果中。
- 多种养地块能在对应多个种类筛选中出现。
- 无结果时显示空状态，可返回全部地块。
- 农场切换后重新加载当前农场数据，不展示旧农场列表。
- 通过前端 TypeScript 检查和微信小程序构建。

## 5. R6：开始种养流程中间页

### 5.1 目标

统一首页、农场 Tab 空状态和地块详情的“开始种养”入口，恢复“选择种类／品种 → 填写种养信息”的连续流程，不再跳转首页或直接从种类列表开始。

### 5.2 页面与交互

- 新增 `pages/productions/start` 页面，页面标题为“开始种养”。
- “种类”为必填项，点击后复用现有 `pages/species/index` 选择种类。
- “品种”为选填文本，留在开始种养页面填写。
- 开始种养中间页不使用外层卡片，页面背景直接承载表单；种类选择框和品种输入框保留自身边界。
- 点击“下一步”后进入 `pages/productions/form`。
- 种养表单固定展示已选种类和品种，用户返回上一步修改；地块、日期、种植标准、数量和备注等字段保持不变。
- 从地块详情进入时携带 `plotId` 并预选地块；从首页和农场 Tab 进入时仍由表单选择地块。

### 5.3 验收

- 首页、农场 Tab 空状态、地块详情均进入新的开始种养页面。
- 未选择种类时“下一步”不可提交，并提示选择种类。
- 选择种类后可返回开始页面，已选种类正确展示。
- 品种为空或有值时均可进入种养表单。
- 种养表单中种类和品种不可直接修改，返回上一步后可修改。
- 创建成功后返回原始入口页面，不回到首页。

## 6. R4：农场级生产记录页

### 6.1 目标

提供当前农场范围内的统一生产记录查询，不要求用户先进入具体地块。

### 6.2 页面结构

页面标题为“生产记录”，顶部提供固定类型筛选：

```text
全部  种养  农事  收获
```

记录按业务时间倒序排列：

- 种养：开始种养、结束种养。
- 农事：FarmOperation。
- 收获：HarvestRecord。

“全部”筛选混合展示三类记录；各类型筛选只展示对应记录。列表行进入相应种养或记录上下文。

### 6.3 后端计划

不得在前端遍历全部地块后合并分页数据。新增农场级聚合查询，例如：

```text
GET /api/v1/farms/{farmId}/records?type=ALL&page=1&pageSize=20
```

接口要求：

- 使用统一的带类型判别字段的 Response DTO，不直接返回 SQLAlchemy Model。
- 按业务时间统一倒序并在后端分页。
- 所有查询检查当前用户的 FarmMember 权限。
- `type` 支持 `ALL`、`PRODUCTION`、`OPERATION`、`HARVEST`。
- 明确开始种养与结束种养的事件时间口径。
- 不引入新的基础设施或事件总线。

### 6.4 前端计划

- 新增 `pages/records/index` 页面与路由。
- 进入页面时携带当前 `farmId`，农场切换后不得继续展示旧农场记录。
- 筛选切换时重置分页并显示明确加载状态。
- 复用首页已有的种养、农事和收获行为图标；图标表达记录类型，不表达具体物种。
- 统一使用 `formatNumber` 展示业务数值。

### 6.5 测试与验收

- OWNER、ADMIN、MEMBER 均可查看已加入农场的记录。
- 未加入农场的用户不能访问记录。
- 多地块记录能够按业务时间正确混排。
- 各筛选类型的总数、分页和排序正确。
- 一个地块多条 ACTIVE Production、无 Production 农事和多次收获均能正确展示。
- 农场切换、空状态、加载失败和分页结束状态正确。
- 后端通过 pytest、Ruff 与 Alembic 检查；前端通过 TypeScript 检查和微信小程序构建。

## 9. R8：地块详情页样式对齐

### 9.1 目标

将地块详情页视觉风格与首页、农场 Tab、我的页对齐：去除大面积浅绿卡片与带边框旧卡片，统一白底浅阴影无边框卡片、`PfRowChevron` 行尾箭头与首页图标资源；理顺信息层级，状态与数量口径使用“批”。

### 9.2 交互与数据口径

- 地块信息卡：类型图标 + 名称主标题 + “类型 · 创建于 YYYY-MM-DD” 辅助行 + 编辑胶囊按钮；分隔线下方仅保留地块面积一个主指标（大数字 + 单位，缺失时以次级色显示“未填写”），右侧状态标签：存在 ACTIVE 批次时 `N 批进行中`，否则 `空闲`。
- 快捷操作（开始种养／记农事／记收获）合并为一张分段白卡，复用首页 `sprout/operation/harvest` 图标；无 ACTIVE 批次时记收获禁用（图标与文字置灰），点击仍提示“暂无进行中的种养”。
- 当前种养空状态改为「图标 + 这个地块目前空闲 + 去开始」轻量行，整行点击进入开始种养；有数据时按批逐行展示：种类名 + 品种标签 + “X月X日开始 · 初始 N 单位”，行内不显示行业图标与重复的“进行中”，行尾使用 `PfRowChevron`。
- 历史种养行文字置灰 + 灰色“已结束”标签，meta 为“X月X日开始 · X月X日结束”。
- 生产记录为菜单式列表卡，计数“共 N 条”移至行尾，行尾使用 `PfRowChevron`。
- 分区标题右侧注释统一批口径：`进行中 N 批`／`共 N 批`／`地块空闲`。
- 权限显隐、路由跳转、加载与失败态保持既有逻辑不变。

### 9.3 实现范围

- 修改 `apps/miniapp/src/pages/plots/detail.vue`。
- 引入复用 `PfRowChevron.vue` 与 `/static/icons/home/` 图标资源。

### 9.4 验收

- 页面不再使用大面积绿色背景与带边框卡片。
- 所有可点击行右侧统一为 `chevron-right.png`，尺寸 30rpx。
- 空闲与种养进行中两种状态的数据口径正确。
- 编辑入口与操作入口的权限显隐不变。
- 通过前端 TypeScript 检查和微信小程序构建。
