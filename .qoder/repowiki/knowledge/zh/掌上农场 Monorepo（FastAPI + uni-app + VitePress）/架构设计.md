根目录作为 monorepo 编排层：`pnpm-workspace.yaml` 将 `packages/*` 共享包与 `apps/miniapp` 小程序纳入同一工作区；顶层 `package.json` 的 scripts 是跨子项目的统一入口——`api:dev` 通过 `uv run --directory apps/api` 启动 FastAPI（8000 端口），`miniapp:dev|build` 通过 `pnpm --filter uni-preset-vue` 驱动微信小程序构建，`docs:*` 直接调用 VitePress。三个子模块之间无共享代码包，仅通过 HTTP API（后端 v1 REST）与文档进行解耦；Node 依赖由根 `package.json` 集中声明（vitepress、vue、mermaid、puppeteer），Python 后端由 uv 独立管理依赖与运行，形成 Node/Python 双栈并行的 monorepo 结构。
