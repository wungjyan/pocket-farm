模块按三层组织：`models/farm.py` 通过 `Base` 声明 `Farm`、`FarmMember` 表及 `FarmMemberRole` 角色枚举，使用 MySQL BIGINT unsigned 主键、CHAR(6) farm_code 唯一码、外键 RESTRICT 以及 farm_id+user_id 联合唯一约束；`schemas/farm.py` 用 Pydantic v2 定义 Create/Update/Response/Page 类，借助 `AliasChoices`/`serialization_alias` 兼容驼峰与下划线字段，并通过 `model_validator` 校验面积与边界坐标系统（强制 GCJ02）；`services/farm.py` 暴露纯函数式异步接口，依赖 `AsyncSession` 执行 SQL 查询与事务，所有写操作先经 `_lock_farm_members` 对 Farm 及所有成员行加 `with_for_update()` 行级锁，再调用 `_require_member_management_role`、`_require_target_permission` 进行基于角色的权限校验，最后统一通过 `_not_found`/`_forbidden`/`_conflict` 包装为带 `ErrorCode` 的 `AppException`。依赖方向单向：service → model/schema，schema 仅引用 model 中的枚举类型，不反向依赖 service。
