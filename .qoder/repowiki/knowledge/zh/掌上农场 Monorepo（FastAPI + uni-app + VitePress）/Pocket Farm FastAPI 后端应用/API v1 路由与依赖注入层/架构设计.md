模块由三部分构成：`router.py` 作为 v1 版本入口，通过 `include_router` 将 `endpoints/` 下每个领域子模块暴露的 `APIRouter`（auth/farms/harvests/operations/plots/productions/species/users）聚合到统一前缀；每个领域文件独立声明自己的 `prefix` 与 `tags`，形成按资源划分的路由边界；`deps.py` 提供两个核心依赖：`get_db_session` 基于 `async_session_factory` 以异步生成器方式提供单请求生命周期会话，并在异常时自动 rollback；`get_current_user` 基于 `HTTPBearer` + PyJWT 解码 + 用户查询，未携带或无效 token 时抛出 `AppException(UNAUTHORIZED)`。端点函数仅做参数校验、调用 `app.services.*` 中的领域服务并返回统一的 `ApiResponse` 包装响应，不直接操作数据库或模型，形成 `router → service → model` 的单向依赖方向。
