模块由单文件 Vue 组件 PfBusinessIcon.vue 与静态资源目录 static/icons/business/ 组成，依赖方向单向：组件指向静态 PNG 资源，无外部服务调用。组件使用 script setup lang=ts 暴露 BusinessIconName 联合类型作为受控白名单（sprout/shovel/shopping-basket/land-plot/list/clock-3/settings/map），并通过 computed 将 name 拼接为 /static/icons/business/${name}.png 路径；模板层仅渲染微信小程序原生 view 与 image 组件，样式采用 BEM 命名（.pf-business-icon--size/--variant/--muted），尺寸与变体通过 CSS 类组合控制，背景色与圆角来自设计令牌 ../styles/design-tokens.scss。新增图标需同时添加类型声明与对应 PNG 文件，保持类型与资源一一对应。
