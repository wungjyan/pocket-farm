模块按职责分为三层：
- 页面层（pages/farms/*、pages/farm/index.vue、pages/farm-plots/index.vue）：基于 Vue 3 `<script setup>` 的单文件组件，分别负责农场 CRUD/成员管理、农场概览（组合 services/plot 与 services/production 聚合 plot 与 active production）、按 species/idle 筛选的地块列表。
- 状态层（services/farm-context.ts）：通过 `useFarmContext()` Hook 暴露 `currentFarm`/`currentFarmName`/`hasCurrentFarm`/`selectFarm`/`syncAvailableFarms`/`refreshFromApi`/`clearFarm`，使用 Vue ref/computed 维护跨页面共享的「当前农场」，并以 `uni.getStorageSync('pocket_farm_current_farm')` 持久化；同时导出 `toFarmSummary` 将后端 Farm 实体映射为前端摘要。
- 服务层（services/farm.ts）：集中封装所有 `/farms*` REST 接口（getMyFarms/createFarm/updateFarm/getFarm/getFarmMembers/addFarmMember/updateFarmMember/removeFarmMember/leaveFarm），页面仅调用这些函数而不直接拼接 URL。
依赖方向单向：页面 → farm-context → farm.ts → http.request；farm 概览页进一步组合 services/plot 与 services/production 完成聚合。路由跳转统一通过 uni.navigateTo/reLaunch 携带 farmId、filter 等 query 参数。
