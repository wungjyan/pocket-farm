- API 调用统一通过 `services/http` 的 `request` 函数发起，并在页面中捕获 `ApiRequestError`，当 `statusCode === 401` 时调用 `clearAuthToken()` 并重定向到登录页。
- 页面遵循 loading → error → data 三态渲染：使用 `loading`、`loadError` 与数据 ref 配合 `v-if/v-else-if` 分支显示加载骨架、错误重试卡片或实际内容。
- 地块类型与单位在多处通过本地 `Record<PlotType, string>` / `Record<AreaUnit, string>` 映射表转换为中文标签（如 FIELD→大田、MU→亩），保持视图层与类型解耦。
- 表单逻辑复用 `components/PlotForm.vue`，页面只负责接收 `@submit` 事件进行校验（名称必填、面积与单位同空同非空）并调用对应 service 方法。
- 导航通过 `uni.navigateTo` 拼接 URL 查询参数传递上下文（如 `farmId`、`plotId`、`plotLocked`），并在 `onLoad` 中解析为本地 ref。
- 权限判断集中以 computed 形式基于 farm 角色（OWNER/ADMIN）控制“创建/编辑/记农事/记收获”等入口的显隐。
