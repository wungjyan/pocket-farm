- 服务层按资源维度组织函数，每个 CRUD 操作对应一个独立导出函数，URL 以模板字符串拼接 `/farms/:id/...` 或 `/productions/:id` 形式。
- API 参数通过查询字符串手动拼接（如 `page=1&pageSize=20`），可选字段仅在存在时追加到参数数组中。
- 页面内筛选条件使用 `ref` 存储值，配合 `computed` 计算 picker 索引与显示标签，并在变化时重新调用数据加载函数。
- 网络请求统一通过 `services/http` 的 `request<T>` 泛型函数发起，页面侧统一 catch `ApiRequestError` 并按状态码做差异化处理。
