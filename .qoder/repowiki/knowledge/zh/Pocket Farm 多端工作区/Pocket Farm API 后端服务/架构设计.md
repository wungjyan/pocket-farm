应用入口 `app/main.py` 在启动时创建 FastAPI 实例、注册全局异常处理器并挂载健康检查与健康端点；v1 路由由 `app/api/v1/router.py` 聚合各业务子路由（auth/farms/plots/operations/productions/species/harvests/users），所有 HTTP 端点仅做参数校验与调用对应 `app/services/*` 中的异步领域服务，再由 `app/models/*` 的 SQLAlchemy 模型经 `app/db/session` 提供的异步会话访问数据库，数据迁移由 `alembic` 管理。测试套件通过 httpx ASGI 传输直接驱动同一 FastAPI 实例进行端到端验证，形成「路由层 → 领域服务 → ORM 模型」的单向依赖结构。
