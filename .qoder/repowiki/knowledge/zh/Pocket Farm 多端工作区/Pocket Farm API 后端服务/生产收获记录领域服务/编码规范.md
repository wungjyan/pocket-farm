- 领域服务函数统一以 `session: AsyncSession` 为首参，并使用 keyword-only 参数接收业务入参，便于扩展与测试注入。
- 权限与存在性校验通过调用上层 `get_*_with_member` 并在可选时传入 `lock=True` 触发 `with_for_update()` 行级锁。
- 业务错误统一由 `_not_found` / `_conflict` / `_validation_error` 三个工厂函数构造 `AppException`，避免在调用方散落状态码。
- Pydantic 请求模型使用 `ConfigDict(extra="forbid")` 拒绝未知字段，并通过 `AliasChoices` 同时接受驼峰与下划线两种命名风格。
- 数值字段使用 `Decimal` 配合 `Field(gt=0, max_digits=14, decimal_places=4)` 在 schema 层做范围与精度校验，再在服务层按 `QuantityUnit` 判定是否要求整数。
