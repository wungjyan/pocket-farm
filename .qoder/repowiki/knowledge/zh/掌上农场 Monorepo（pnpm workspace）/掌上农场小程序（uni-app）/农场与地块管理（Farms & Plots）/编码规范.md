- 所有 HTTP 请求集中在 services/farm.ts 中按 REST 资源组织（getMyFarms/createFarm/updateFarm/getFarmMembers/addFarmMember/removeFarmMember/leaveFarm），页面仅调用这些函数而不直接拼接 URL。
- 当前农场状态通过 useFarmContext() 响应式 Hook 提供 currentFarm/currentFarmName/hasCurrentFarm/selectFarm/syncAvailableFarms/refreshFromApi/clearFarm，页面在 onShow 中调用 refreshFromApi 同步可用农场列表。
- API 错误处理统一捕获 ApiRequestError，当 statusCode === 401 时调用 clearAuthToken 并 uni.reLaunch 到 /pages/auth/login，其他错误通过 uv-toast 或本地 loadError 字段提示。
- 农场实体到前端摘要的转换统一通过 toFarmSummary 函数完成，避免在各页面重复映射 Farm 字段。
- 页面加载流程遵循 loading/error/empty/data 四态模板分支，并在 finally 中重置 loading 标志。
- 跨页面导航统一使用 uni.navigateTo 并携带 farmId、filter 等 query 参数，而非全局状态传递业务标识。
