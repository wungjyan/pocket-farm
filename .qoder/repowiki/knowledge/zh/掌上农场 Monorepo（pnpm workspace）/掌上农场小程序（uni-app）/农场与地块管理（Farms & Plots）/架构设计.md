模块以 pages/ 下的 Vue 单文件组件为页面层，services/farm.ts 通过统一 request 封装暴露农场 CRUD 与成员管理的 API 函数，services/farm-context.ts 基于 Vue ref/computed 实现跨页面共享的「当前农场」状态，并通过 uni.getStorageSync 持久化 key `pocket_farm_current_farm`。
- 页面分层：`pages/farms/`（农场列表/创建/编辑/成员）、`pages/farm/index.vue`（农场概览，聚合地块与生产数据）、`pages/farm-plots/index.vue`（按物种/空闲筛选地块列表）。
- 依赖方向：页面 → farm-context（选择/刷新当前农场）→ farm.ts（调用 `/farms*` REST 接口）；farm 概览页进一步组合 plot 与 production 服务完成聚合。
- 路由跳转统一通过 uni.navigateTo / reLaunch 到 `/pages/farms/*`、`/pages/farm-plots/index?farmId=...&filter=...` 等路径，401 时统一走 clearAuthToken + 重定向登录。
