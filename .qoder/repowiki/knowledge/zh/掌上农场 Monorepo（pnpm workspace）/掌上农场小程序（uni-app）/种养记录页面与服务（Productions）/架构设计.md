模块以 uni-app Vue 3 `<script setup>` 单文件组件组织，按业务动作拆分为五个页面：`start.vue` 负责选择种类与品种并通过 `eventChannel` 将 species 信息传递给下游；`form.vue` 监听上游 setup 事件并调用 `createProduction` 新建记录；`edit.vue` 加载已有记录并通过 `updateProduction` 更新；`detail.vue` 展示字段并根据 `industry` 动态渲染标签，跳转 harvests 与 end 流程；`end.vue` 选择结束日期后调用 `endProduction`。所有数据访问集中在 `services/production.ts`，该文件定义 `Production`、`ProductionInput`、`ProductionUpdateInput`、`EndProductionInput`、`ProductionStatus`、`PlantingStandard`、`PlantingMethod`、`WorkMethod` 等类型以及基于 `request` 的 CRUD 函数，依赖 `species` 中的 `Industry`、`IndividualUnit`、`Species` 类型，形成 pages → services → http 的单向依赖。页面之间通过 `uni.navigateTo` 的 URL query 与 `eventChannel` 进行跨页通信，并与 `pages/species/index`、`pages/plots/index`、`pages/harvests/*` 等其他模块协作。
