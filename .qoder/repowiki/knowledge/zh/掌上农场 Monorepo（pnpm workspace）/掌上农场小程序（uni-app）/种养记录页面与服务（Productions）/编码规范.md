- 页面统一采用 loading / loadError / data 三段式模板分支，配合 `state-card` 展示加载中与错误重试 UI。
- 401 未授权异常统一通过 `handleUnauthorized` 调用 `clearAuthToken()` 后 `uni.reLaunch` 跳转登录页处理。
- 枚举值（Industry、PlantingStandard、PlantingMethod、WorkMethod、IndividualUnit 等）在页面内以 `Record<T, string>` 映射表转中文显示。
- API 调用包裹 try/catch，成功时通过 `uv-toast` 提示 success/error，失败时区分 `ApiRequestError` 回显后端消息或兜底文案。
- 表单类页面使用 `useUnsavedChangesGuard(dirty)` 监听 `@change` 事件标记脏状态，防止误退出丢失数据。
- 跨页传参采用 `uni.navigateTo` 的 URL query 与 `eventChannel` 组合：start→form 用 eventChannel 传递 species，其余页面多用 URL 参数传递 id。
