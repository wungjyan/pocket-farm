模块按分层组织：`models/user.py` 通过继承 `app.db.base.Base` 定义 `User` 表（users），使用 `sqlalchemy.orm.Mapped` + `mapped_column` 声明字段，并以 `utc_now_naive()` 作为默认值处理 MySQL DATETIME；`services/auth.py` 暴露 `login_with_verification_code`，先校验 `settings.test_login_enabled` 与 `settings.test_login_code`，再查询或创建用户并处理并发插入的 `IntegrityError` 冲突；`services/user.py` 暴露 `update_current_user` 用于更新当前用户的 nickname。依赖方向单向：service → model → Base，service 通过注入的 `AsyncSession` 访问数据库，不持有持久化状态，由上层路由/控制器传入 session。
