- 枚举类型以 `StrEnum` 形式在 models 层定义并直接复用为 Pydantic schema 字段类型，保证数据库值与 API 契约一致。
- Pydantic schema 通过 `Field(serialization_alias=...)` 将 Python 下划线字段序列化为前端期望的驼峰命名。
- Service 层函数统一采用 `async def` 签名并以关键字参数（`*`）暴露可选过滤条件，返回 `(items, total)` 元组配合分页使用。
- 查询构建使用 SQLAlchemy `select` + `where(*filters)` 动态拼接过滤条件，再叠加 `order_by`、`offset`、`limit` 完成分页。
