模块按三层划分：`models/species.py` 通过 SQLAlchemy ORM 定义 `Species` 表及 `Industry`、`IndividualUnit` 两个 `StrEnum` 枚举；`schemas/specpecies.py` 使用 Pydantic 定义 `SpeciesResponse` 与 `SpeciesPage` 分页结构，并通过 `Field(serialization_alias=...)` 将驼峰字段映射到数据库下划线字段；`services/species.py` 提供 `list_species` 异步函数，接收 `AsyncSession` 与可选过滤参数（industry、keyword）、分页参数，使用 `select` + `func.count` 实现带条件过滤的分页查询并按 industry/name/id 排序。依赖方向单向：service → model → Base，schema 仅用于序列化输出，不反向依赖 service。
