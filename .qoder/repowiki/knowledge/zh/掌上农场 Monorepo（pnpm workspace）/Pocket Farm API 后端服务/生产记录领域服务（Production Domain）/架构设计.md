模块按三层职责划分：`models/production.py` 通过 SQLAlchemy ORM 定义 `Production` 表及 `ProductionStatus`、`PlantingStandard`、`PlantingMethod`、`WorkMethod`、`QuantityUnit` 等枚举；`schemas/production.py` 使用 Pydantic v2 的 `AliasChoices` 同时支持驼峰与下划线字段名，定义 `CreateProductionRequest`、`UpdateProductionRequest`、`EndProductionRequest`、`ProductionResponse`、`ProductionPage` 等 DTO；`services/production.py` 作为领域服务层，封装所有异步数据库操作，依赖 `Plot`、`FarmMember`、`Species`、`FarmOperation`、`HarvestRecord` 等相邻模型完成跨实体校验与状态流转。服务内部通过 `_get_plot_with_member`、`get_production_with_member`（可选 `with_for_update()` 行锁）实现权限与并发控制，并通过 `_validate_industry_fields` 根据物种所属 `Industry`（农业/林业/畜牧业/其他）动态强制或禁止特定字段，从而在同一套 API 中支撑多行业生产记录。
