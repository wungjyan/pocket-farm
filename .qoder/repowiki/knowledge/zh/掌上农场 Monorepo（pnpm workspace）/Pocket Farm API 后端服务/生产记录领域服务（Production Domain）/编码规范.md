- 领域服务中的异常统一通过 `_not_found`、`_conflict`、`_validation_error` 三个工厂函数构造 `AppException`，并按 HTTP 状态码分类抛出。
- 对需要并发安全的读取/更新操作，通过 `get_production_with_member(..., lock=True)` 在 SELECT 末尾追加 `with_for_update()` 进行行级锁定。
- 跨实体权限校验统一先调用 `get_plot_with_member` 或 `get_production_with_member`，确保当前用户对该地块/生产记录拥有访问权后再执行业务逻辑。
- 字段有效性校验按行业分支集中到 `_validate_industry_fields`，使用 `_require` / `_forbid` 辅助函数对必填与禁用字段进行声明式检查。
- Pydantic 请求/响应模型通过 `Field(validation_alias=AliasChoices(...), serialization_alias=...)` 同时兼容前端驼峰命名与后端下划线属性。
- 可空枚举字段在更新时通过 `fields_set` 集合判断是否变更，并在未设置时回退为原值，避免覆盖已有数据。
