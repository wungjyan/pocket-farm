- 每个测试模块定义同构的 `request_api(path, method, json, headers)` 异步函数，内部用 `httpx.AsyncClient(transport=ASGITransport(app=app))` 发起请求并在返回后调用 `engine.dispose()`。
- 通过登录 `/api/v1/auth/login` 并解析 `response.json()['data']['accessToken']` 获取 token，再以 `Authorization: Bearer <token>` 头调用受保护接口。
- 断言统一检查响应体的 `success` / `error` / `data` 三段式信封结构，并通过 `error.code`（如 UNAUTHORIZED、VALIDATION_ERROR、NOT_FOUND、FORBIDDEN、BUSINESS_CONFLICT）判断错误类型。
- 使用预分配的手机号常量（如 OWNER_PHONE、ADMIN_PHONE、MEMBER_PHONE）配合 `13800000001..6` 范围标识不同角色，便于在清理逻辑中批量定位并删除关联数据。
- 将重复的 API 调用封装为模块级 helper（如 login、call、create_farm、record_operation、record_harvest），使测试用例仅表达业务步骤而非网络细节。
