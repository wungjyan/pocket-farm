- 每个领域在 `endpoints/` 下以独立文件组织，文件内创建带 `prefix` 和 `tags` 的 `APIRouter`，并在 `router.py` 中集中 `include_router` 注册。
- 需要鉴权的端点通过 `Depends(get_current_user)` 获取当前 `User`，数据访问通过 `Depends(get_db_session)` 注入 `AsyncSession`，两者组合使用。
- 所有成功响应统一通过 `ApiResponse.success_response(data=...)` 包装，失败路径抛出 `AppException`，避免在各端点重复构造错误体。
- 请求/响应类型均使用 Pydantic schema（`schemas/*`），端点函数签名直接使用这些 schema，并通过 `model_validate` 将 ORM 模型转为响应对象。
- 分页参数统一使用 `Annotated[int, Query(ge=1)]` 等注解进行入参校验，列表接口返回 `*Page` 类型的分页结构。
