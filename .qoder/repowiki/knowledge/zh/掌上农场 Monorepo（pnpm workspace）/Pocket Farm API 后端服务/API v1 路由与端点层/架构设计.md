模块采用 FastAPI 的分层路由组织：`router.py` 作为 v1 版本入口，通过 `include_router` 将 `endpoints/` 下每个领域子模块暴露的 `APIRouter` 聚合到统一前缀；每个领域文件（auth/farms/harvests/operations/plots/productions/species/users）独立声明自己的 `prefix` 与 `tags`，实现按资源划分的路由边界。依赖注入集中在 `app/api/deps.py`，提供 `get_db_session`（基于 `async_session_factory` 的异步会话生命周期管理，异常时自动 rollback）和 `get_current_user`（基于 `HTTPBearer` + JWT 解码 + 用户查询），被各端点以 `Depends` 复用。端点本身仅做参数校验、调用 `app.services.*` 中的领域服务并返回统一的 `ApiResponse` 包装响应，不直接操作数据库或模型，形成 `router → service → model` 的单向依赖方向。
