模块按三层划分：`models/plot.py` 定义 `Plot` ORM 模型及 `PlotType`、`AreaUnit` 等 StrEnum；`schemas/operation.py` 使用 Pydantic v2 的 `AliasChoices` 同时支持驼峰与下划线字段，完成创建/更新请求与分页响应的校验与序列化；`services/plot.py` 是领域服务层，通过 SQLAlchemy 异步查询与 `get_farm_with_member` 进行农场成员权限校验，仅允许 OWNER/ADMIN 管理地块。服务内部以纯函数形式暴露 `list_plots`、`create_plot`、`get_plot_detail`、`update_plot` 等用例，依赖方向单向指向 models/schemas，并通过 `calculate_area_m2` 统一将亩/公顷换算为平方米存储。`update_plot` 使用 `with_for_update()` 行级锁配合 `fields_set` 实现部分更新，避免覆盖未传入字段。
