模块按职责划分为三个子包：`core/` 承载应用级横切关注点——`config.py` 基于 pydantic-settings 从环境变量/.env 加载 Settings（含数据库 URL、JWT 密钥、时区等），被 `security.py`（使用 PyJWT 生成/解码 HS256 JWT）和 `db/session.py` 消费；`exceptions.py` 定义统一业务异常 `AppException` 及 `ErrorCode` 枚举，并通过 `register_exception_handlers` 在应用启动时注册四个 FastAPI 异常处理器（业务异常、请求校验异常、HTTP 异常、未捕获异常），所有错误响应统一走 `ApiResponse.error_response`；`db/` 封装 SQLAlchemy 异步引擎与 Session 工厂，`base.py` 通过 `DeclarativeBase` 与命名约定集中管理约束命名规则，`session.py` 暴露单例 `engine` 与 `async_session_factory`；`main.py` 作为入口，使用 `lifespan` 钩子在应用关闭时调用 `engine.dispose()`，并通过 `create_application` 组装 FastAPI 实例、注册异常处理器、挂载 health 与 v1 路由。依赖方向单向：`main → core/db → core/config`，`core/security` 仅依赖 `core/config`，不反向依赖业务层。
