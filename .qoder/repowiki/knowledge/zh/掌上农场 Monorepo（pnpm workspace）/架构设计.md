根目录通过 `pnpm-workspace.yaml` 将 Node 子项目（`apps/miniapp`、`packages/*`）纳入同一工作区，并以顶层 `package.json` 的 scripts 作为跨子项目的统一入口：`api:dev` 在 `apps/api` 下用 uv 启动 FastAPI，`miniapp:dev|build` 通过 `pnpm --filter` 驱动 uni-preset-vue 构建，`docs:*` 直接调用 VitePress。三个子模块之间无共享代码包，仅通过 HTTP API（后端 v1 REST）与文档进行解耦；`AGENTS.md` 中的开发原则（Alembic 迁移、AsyncSession + aiomysql、Router/Service 分层、FarmMember 权限校验等）在后端生效，并作为前后端协作的业务契约约束 miniapp 的数据展示方式。
